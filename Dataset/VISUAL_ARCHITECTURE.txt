SUCCESS FLOW SUMMARY
═══════════════════════════════════════════════════════════════════════════════════

1️⃣  USER describes need in natural language
     ↓
2️⃣  CLARIFIER asks questions until fully understands (max 5 rounds)
     ↓
3️⃣  GENERATOR creates Python code with type hints & docstrings
     ↓
4️⃣  3 TEST LLMs independently generate comprehensive test suites
     ↓
5️⃣  EXECUTOR runs all 3 test suites and collects results
     ↓
6️⃣  VALIDATOR checks if at least 2/3 test suites pass
     ↓
     ├─► ✅ If YES: Success! Show code, offer save
     │
     └─► ❌ If NO:  Send feedback to generator
                    Revise code (iteration 2-5)
                    Re-test
                    ↓
                    Repeat until success or max iterations
                    ↓
                    If still failing: Request human help
