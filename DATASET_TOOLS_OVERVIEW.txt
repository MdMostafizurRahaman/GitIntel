🚀 QUICK START COMMANDS
================================================================================

Basic Operations:
  1. Verify Installation:
     python verify_installation.py

  2. List All Datasets:
     python -m cli.main list-datasets

  3. Extract Data:
     python -m cli.main extract \
       --dataset-type defects4j \
       --source /path/to/repo \
       --output data.json

  4. Process Data:
     python -m cli.main process \
       --input data.json \
       --output processed.json \
       --normalize-code --clean-text

  5. Label Data:
     python -m cli.main label \
       --input data.json \
       --output labeled.json \
       --label-type bug_severity

  6. Import to Neo4j:
     python -m cli.main import-to-neo4j \
       --input labeled.json \
       --dataset-name "My Dataset"

GUI Tools:
  7. Launch Autonomous Agent GUI:
     python gui/autonomous_gui.py

  8. Launch Metrics Selector GUI:
     python gui/metrics_selector_gui.py

API Server:
  9. Start API Server:
     python api/server.py
     (Access at http://127.0.0.1:8000/docs)
